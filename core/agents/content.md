# Content and Writing Rules

## ASD-STE100 Summary (CONDITIONAL)

Do not constrain the main response to ASD-STE100. Preserve normal vocabulary,
nuance, technical precision, and depth.

When a concise recap helps after a substantive technical response, add a final
`Summary` section. Write only that section in an ASD-STE100-inspired style. Use
active voice, concrete words, stable terms, and short sentences. Limit the
summary to one to three sentences.

Omit the summary when it repeats the response or adds no useful information.
Omit it for short replies, code-only output, creative writing, translations,
localization, language-learning output, and requested non-English output.

If the user explicitly requests ASD-STE100, apply it only to the requested scope.
Always preserve verbatim code, commands, structured data, names, identifiers,
error text, citations, quotations, and supplied source material.
