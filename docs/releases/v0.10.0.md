# jarvos-bootstrap v0.10.0

Release Please proposal: [#241](https://github.com/levineam/jarvOS/pull/241).

## Summary

v0.10.0 is the current public preview release of `jarvos-bootstrap`. It brings
the public portable runtime contracts, safer initialization and synchronization,
Projects-context handling, and GBrain-first integration work into one release.

## What's Included

- Portable runtime and harness contracts, including capability-ledger and
  constrained-generation boundaries.
- Safer new and existing-installation initialization, plus read-only compatible
  installation synchronization.
- Projects-context contracts that carry consistent project information across
  supported harnesses and fail closed on inconsistent bindings.
- GBrain-first resolver integration and public integration documentation.
- Profile-aware System Doctor checks and storage-capacity safeguards.

## Fixes

- Hardened vault containment, symlink handling, runtime-path resolution, and
  configuration normalization during initialization and synchronization.
- Strengthened public capture, journal, control-plane, and runtime evidence
  boundaries.

## Breaking Changes

- None known for the documented public bootstrap interface.

## Known Limitations

- jarvOS remains local-first. Public packages do not include private host
  credentials, project records, vault contents, or managed runtime state.
- Optional integrations require a compatible local host configuration; an
  unconfigured integration remains unavailable rather than using developer
  defaults.

## Install / Update

```bash
git clone https://github.com/levineam/jarvOS.git
cd jarvOS
npm ci
npm test
```

For an existing clone:

```bash
git pull origin main
npm ci
npm test
```
